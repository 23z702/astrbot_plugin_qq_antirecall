# QQ 防撤回（astrbot_plugin_qq_antirecall）

仓库地址：https://github.com/23z702/astrbot_plugin_qq_antirecall

给 AstrBot 用的 QQ 防撤回插件：缓存群聊 / 私聊中的**文本、图片、视频**，消息被撤回时把「群号、被撤回的人、谁撤回的、撤回内容」记到日志，可用指令随时查看，也可以选择发回原会话或转发到指定群 / 人。

仅支持 `aiocqhttp`（OneBot v11）平台，例如 NapCat、Lagrange。

## 功能

- **文本**：完整保留文本内容，超长自动截断（默认 2000 字）
- **图片**：缓存图片并在撤回后重发；开启媒体落盘后不受图片链接过期影响
- **视频**：缓存视频文件，撤回后重新发送
- **群聊 / 私聊**：都支持；群聊可用白名单限定范围
- **撤回日志（默认）**：记录群号、被撤回的人、撤回操作者、文本和图片/视频数量，`/撤回记录` 查看，不往群里刷屏
- **撤回提示**：区分「本人撤回」和「管理员撤回他人消息」，模板可自定义
- **转发模式**：可以只把撤回内容发到指定群 / 指定人，而不是原会话
- **自动清理**：按 TTL 清理内存记录和磁盘媒体，缓存条数有上限

## 安装

1. 把整个 `astrbot_plugin_qq_antirecall` 目录放到：

   ```
   AstrBot/data/plugins/astrbot_plugin_qq_antirecall
   ```

   桌面版一般是 `%USERPROFILE%\.astrbot\data\plugins\`。

2. 打开 AstrBot 管理面板 → 插件 → 重载插件（或重启 AstrBot）。
3. 在插件配置页按需调整开关。

无第三方依赖，不需要额外 `pip install`。

## 指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/撤回记录` | 管理员 | 查看最近 10 条撤回记录（群号、被撤回的人、谁撤回的、内容） |
| `/撤回记录 20` | 管理员 | 查看最近 20 条，最多 50 |
| `/撤回记录 #群号` | 管理员 | 只看某个群的撤回记录 |
| `/撤回记录 清空` | 管理员 | 清空撤回日志 |
| `/防撤回状态` | 管理员 | 查看开关、缓存条数、媒体落盘状态、撤回内容去向、转发目标 |
| `/撤回转发 #群号 @QQ号` | 管理员 | 设置撤回内容的转发目标，可写多个，立即生效并保存 |
| `/撤回转发 查看` | 管理员 | 查看当前转发目标 |
| `/撤回转发 清空` | 管理员 | 恢复为发送到原会话 |

`/撤回记录` 输出示例：

```
最近 2 条撤回记录：
1. 2026-11-01 20:21:58 | 群 1079587491
   被撤回：张三(111) · 本人撤回
   内容：我发了不该发的
2. 2026-11-01 20:21:59 | 群 1079587491
   被撤回：李四(222) · 被 管理员(333) 撤回
   内容：图片消息  [图片×1]
```

## 撤回内容去向（delivery_mode）

默认 **只写日志**，不往群里发，避免刷屏；用 `/撤回记录` 查看。

| 模式 | 行为 |
| --- | --- |
| `log`（默认） | 只记录到日志文件和 AstrBot 日志，不发任何群消息 |
| `session` | 把「提示 + 原文 + 图片 + 视频」发回原会话 |
| `forward` | 发到 `forward_targets` 指定的群 / 人（未设置则发回原会话） |

日志文件：`data/plugin_data/astrbot_plugin_qq_antirecall/recall_log.jsonl`，一行一条 JSON，字段包括
`time` `chat_id` `sender_id` `sender_name` `operator_id` `operator_name` `self_recall` `text` `images` `videos` `media` `message_id`。

示例：

```
/撤回转发 #1079587491          → 只发到这个群
/撤回转发 @105090254           → 只发给这个人（私聊）
/撤回转发 #1079587491 @105090254 → 两个地方都发
```

`#` 开头是群，`@` 开头是私聊。只有在 `delivery_mode=forward` 时才走转发目标。

## 配置要点

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | 开 | 总开关 |
| `cache_ttl` | 300 秒 | 缓存保留时间。QQ 普通成员撤回时限 2 分钟，管理员可撤回更早消息 |
| `download_media` | 开 | 收到图片 / 视频后异步下载到 `data/plugin_data/astrbot_plugin_qq_antirecall/media` |
| `max_media_mb` | 30 | 单个媒体落盘体积上限，超限则退回用原始链接 |
| `recall_wait_media` | 8 秒 | 撤回时最多等媒体下载完成的时间 |
| `delivery_mode` | `log` | 撤回内容去向：`log` 只写日志 / `session` 发回原会话 / `forward` 发到转发目标 |
| `log_enabled` | 开 | 是否记录撤回日志 |
| `log_keep` | 1000 | 日志文件超过 2MB 时保留的最近条数 |
| `group_whitelist` | 空 | 只监控这些群号；空 = 所有群 |
| `user_blacklist` | 空 | 不监控这些 QQ |
| `forward_targets` | 空 | 填 `#群号` / `@QQ号`（或 `group:` / `private:`），撤回内容只发到这些会话 |
| `silent_when_missing` | 开 | 缓存未命中时不提示 |

提示模板支持的占位符：

- `{sender_name}` `{sender_id}`：原消息发送者
- `{operator_name}` `{operator_id}`：撤回操作者
- `{group_id}` `{chat_id}` `{time}`

## 工作原理

1. 插件以高优先级监听所有 OneBot 事件。
2. 普通消息事件：把 `message_id`、会话、发送者以及文本 / 图片 / 视频片段写入内存缓存；媒体在后台异步落盘，不阻塞消息处理。
3. `group_recall` / `friend_recall` 通知事件：用 `message_id` 找到缓存，先写一条撤回日志（群号、被撤回者、操作者、内容），再按 `delivery_mode` 决定是否发送。
4. 后台每 60 秒清理过期记录和孤儿媒体文件。

## 注意事项

- **只支持 OneBot v11（aiocqhttp）**。QQ 官方机器人接口不提供撤回事件，无法支持。
- **AstrBot 与协议端分离部署时**（例如 NapCat 在 Docker 里、AstrBot 在宿主机），协议端读不到插件目录里的本地视频文件，视频补发可能失败。两种处理方式：
  1. 关闭 `download_media`，改用原始链接兜底（链接未过期时可用）；
  2. 给容器挂载共享目录，让协议端能访问同一个媒体路径。
- **缓存只在内存中**，插件重启后之前的消息无法补发；重启前的撤回不会提示。
- **管理员撤回更早的消息**时，只要还在 `cache_ttl` 范围内就能补发，可适当调大该值。
- 媒体文件保存在 `data/plugin_data/`，不会随插件更新丢失；TTL 到期自动清理。
